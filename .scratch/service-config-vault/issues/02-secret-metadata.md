## Question

在敏感性已经绑定逻辑配置键、环境覆盖不能隐式取消标记的前提下，如何精确定义嵌套配置的敏感范围及脱敏语义，保证默认查看和导出不会因结构变化泄露值？

需要与用户确定：

- 标记对象或数组时是否覆盖全部后代；父级敏感性与子级标记如何交互。
- 环境覆盖使值在对象、数组和标量之间变化时，原有标记如何继续生效。
- 删除配置、恢复继承、显式取消标记时，元数据如何处理；取消标记不能由写入新值隐式触发。
- 如何表示已隐藏的值并与真实字符串、`null` 或缺失键区分；脱敏元数据是否会暴露不应显示的子键。
- 业务程序读取真实值与面向用户的脱敏查看怎样保持清楚区分。

用敏感父对象、敏感数组和环境类型变化的例子确认规则；不在本票设计导出命令或 Go 方法签名。

## Answer

### 逻辑路径上的分类与生命周期

敏感性按 vault 内的逻辑配置路径维护，不是某个环境值的临时属性。默认值、环境覆盖和重新写入均不能隐式清除已有敏感标记。

此前没有分类的新配置值默认敏感，只有显式声明为普通配置才允许明文展示。已有路径的分类继续有效；被敏感祖先覆盖的普通子键仍不能绕过祖先的保护。

删除数据只删除值，不删除路径上的敏感标记。删除环境覆盖、恢复继承、重新新增同一路径后，保留的标记继续生效；取消敏感标记必须显式进行。

将一个对象改为普通配置只取消该对象自身的敏感标记，不递归取消后代标记。对子键取消自身标记，也不能覆盖仍然敏感的祖先。CLI 的 `classify` 与 Go 的 `Classify` 接入见[接口契约](07-cli-go-contract.md#answer)。

### 新对象、结构节点与数组

设置 `/database/host` 而自动创建的中间对象只作为结构，不额外给整个 `/database` 加敏感标记；真正新增且未分类的目标值 `host` 默认敏感。这是“新键默认敏感”对自动结构节点的明确例外，不表示其后续新增子键自动成为普通配置。

整体写入新对象时，目标对象及新增后代键均默认敏感；已有逻辑路径的分类不被写入隐式清除。因此仅取消父对象的标记，不会把新增子键一并暴露。

数组作为一个整体分类和脱敏，不创建元素级标记，也不新增数组元素寻址能力。

### 容器保护与类型遮挡

敏感对象或数组整体隐藏，包括内部成员名称、数量和结构；普通子路径读取也不能绕过父级保护。

如果敏感子路径在所选配置视图中被父级的标量、`null` 或数组遮挡，则在该视图中把造成遮挡的父级整体脱敏。例如保留 `/database/password` 标记，而某环境将 `/database` 覆盖为字符串时，隐藏 `/database`，不因子路径当前不可达而失去保护。

此类型遮挡规则是当前视图的计算结果，不在读取时新增父级标记或删除原子路径标记。父级恢复为对象后，仍按保留的路径与当前结构计算保护范围。

### 脱敏值与元数据

隐藏值以 `null` 表示，数据外提供 `redacted_paths`。整库导出的外层结构见[导出契约](06-json-export.md#answer)，单值查询结构见[接口契约](07-cli-go-contract.md#answer)。普通真实 `null` 不带脱敏标记，敏感值即使本身为 `null`，被隐藏时也带标记。

敏感容器只报告整个容器的保护边界路径，不枚举内部成员或更深的分类路径。持久化分类元数据与对外的已脱敏路径列表是不同概念；不能通过输出完整分类表泄露已隐藏的结构。

已保留但在当前配置中缺失的标记，不凭空创建配置值或在普通整份查看中暴露缺失的内部路径。

### 普通查看与真实读取

先检查请求的 JSON Pointer 语法。语法有效的请求若进入受保护容器，普通查看直接返回脱敏结果，不进一步暴露内部路径是否存在或类型是否匹配；只报告相应保护边界，不展开后代。

这项不透明规则也适用于数组或标量造成的敏感遮挡；显式明文查看及业务程序的真实读取仍遵循已确认的正常路径和错误规则。它不是把明文模式下本应报错的数组元素访问变成受支持操作。

Go 业务调用方取得真实配置值，不取得脱敏占位符。生成脱敏视图不得修改业务配置快照或持久化数据；明文展示必须由用户显式选择，诊断与普通错误输出不能顺带泄露值或敏感结构。

### 已确认的边界示例

| 场景 | 结果 |
| --- | --- |
| `/database` 为敏感对象，内部有普通或敏感子键 | 整个对象显示为 `null`，只报告 `/database`，不展开内部结构 |
| `/servers` 为敏感数组 | 整个数组隐藏，不显示元素数量或元素路径 |
| 删除敏感 `/token`，以后恢复或重新写入 | 敏感标记保留，普通查看仍隐藏该值 |
| 新增未分类的 `/token` | 默认敏感，明文展示需要显式改为普通配置 |
| 自动创建 `/database` 以设置新 `/database/host` | 中间结构不额外标为敏感，`host` 默认敏感 |
| 整体新增对象 `/credentials`，再仅取消其自身标记 | 新增后代的敏感标记仍在，不因取消父标记而全部明文展示 |
| 普通 `/database` 内保留敏感 `/database/password`，某环境把父值替换为字符串或数组 | 该环境视图隐藏整个 `/database`，读取不改动持久化标记 |
| 普通值本身是 `null` | 输出 `null`，不报告该路径为已脱敏 |
| 敏感值本身是 `null` | 同样输出 `null`，但报告该保护边界为已脱敏 |
| 请求敏感对象下的已存在与不存在子路径 | 普通查看均返回保护边界的脱敏结果，不泄露存在性或内部类型 |
| 业务程序或显式明文模式读取 | 获得真实值或正常路径错误，不把脱敏占位符当作配置值 |
