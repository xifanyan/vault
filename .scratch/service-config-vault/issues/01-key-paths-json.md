## Question

在[设计规格](../spec.md)已确认 JSON 值类型、对象递归合并、数组整体替换及 `null` 语义的前提下，如何定义配置寻址与 JSON 读写，使 CLI 和 Go 调用方不会对同一份配置产生不同解释？

需要与用户确定：

- 配置根节点形状；环境名称与默认配置的表示约束，避免选择歧义。
- 含点、斜杠、空字符串或 Unicode 的键如何被无歧义地寻址；是否允许访问数组元素，以及父子路径冲突如何处理。
- JSON 数值在读取、修改和导出时如何保持精度；对象重复键如何处理。
- 使用包含特殊字符键、大整数、数组与显式 `null` 的具体场景验证规则；不重新决定已经确认的合并优先级。

本票产出是经过用户确认的语义和输入输出例子，不是解析器实现。

## Answer

### 配置根节点与环境

默认配置和各环境覆盖层的顶层均为 JSON 对象；成员值可使用 JSON 的其他值类型。默认配置是独立作用域，不通过特殊环境名表示。

环境名称至少有一个字符，只使用小写 ASCII 字母、数字、`-` 和 `_`，首字符为字母或数字，即 `^[a-z0-9][a-z0-9_-]*$`。`dev`、`prod`、`staging-2` 合法；不自动更改大小写或修正非法名称。`default` 若作为环境名使用，只是普通环境，不等于默认配置作用域。

### 键路径与数组

采用 JSON Pointer 的字符串形式，不按点号拆分；`~1` 表示键名内的 `/`，`~0` 表示键名内的 `~`。键名可包含点号、斜杠、空字符串或 Unicode；按解码后的字符串精确匹配，不做大小写折叠或 Unicode 归一化。非法指针语法和转义报错。

空指针 `""` 表示根，允许读取，但禁止写入或删除根。`/` 表示空字符串键，不是根。

配置操作只沿对象成员寻址。数组整体读取和替换，不允许进入数组元素；因此 `/servers/0` 在 `servers` 为数组时不受支持，在 `servers` 为具有 `"0"` 成员的对象时则是正常对象成员路径。

### 配置层写入

写入明确针对默认配置或某个环境的覆盖层，不修改已计算的有效配置。检查路径冲突时只检查正在编辑的存储层，不把另一层继承来的值视为本层已存在的节点。

设置对象成员路径时，缺失的中间对象自动创建；已有中间节点为标量、`null` 或数组时，报错，不隐式替换为对象。目标节点本身可被显式替换，包括替换对象、数组或类型；环境解析时的递归合并规则不等于设置操作的合并规则。

失败的写入不保存部分创建的父对象。删除环境覆盖仍按既定规则恢复继承；所选存储层没有该键时返回 `ErrNotFound`，即使有效配置中能继承该值。具体接入见[接口契约](07-cli-go-contract.md#answer)。

### JSON 保真

- JSON 数值读取、修改和导出保持精度，不默认经由 `float64` 转换。不承诺原始空白或数字书写形式保持不变。
- 已选 Go 接口返回 JSON 原值，不提供隐式数值类型转换，不经由 `float64` 舍入或截断；业务侧 Go 类型解码由调用方负责。完整签名见[接口契约](07-cli-go-contract.md#answer)。
- 同一 JSON 对象内重复键报错，不采用最后值覆盖。重复性按 JSON 字符串解码后的键比较，因此 `"a"` 与 `"\u0061"` 是同一个键。

### 已确认的边界示例

| 场景 | 结果 |
| --- | --- |
| 读取 `""` | 读取整个所选配置对象；对同一路径写入或删除报错 |
| 对 `/` 写入一个值 | 设置名称为空字符串的成员，不替换根对象 |
| `/database/host` 与 `/database.host` | 分别寻址嵌套成员和含点号的单个键 |
| `/a~1b` 与 `/a~0b` | 分别寻址名称为 `a/b` 和 `a~b` 的键 |
| `/服务/地址` | 按 Unicode 键名精确寻址 |
| `servers` 是数组，读取 `/servers/0` | 报错；读取 `/servers` 获得整个数组 |
| 所编辑层为 `{}`，设置 `/database/host` | 创建 `database` 对象并设置其 `host` 成员 |
| 所编辑层中 `database` 是字符串或 `null`，设置 `/database/host` | 报错，原值保持不变 |
| 默认层中 `database` 是标量，环境覆盖层没有该键，在覆盖层设置 `/database/host` | 在覆盖层创建对象；不因默认层的类型而报路径冲突 |
| 对目标键显式设置 `null` | 保存 `null`，不是删除；删除环境覆盖才恢复继承 |
| 读写或导出 `9007199254740993` | 保持精确数值；不能被舍入为相邻数 |
| 解析 `{"port":80,"port":443}` 或 `{"a":1,"\u0061":2}` | 拒绝重复键 |

这些是用户确认的规格示例，不是已经运行的产品测试。本票未新增实现任务或研究票据；原有性能及接入场景的迷雾尚未出现可独立指定的新问题，保留在地图中。
